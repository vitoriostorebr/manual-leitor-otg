🎮 Guia de Uso: Memory Card PS2 Bitfunx

Obrigado por adquirir seu produto com a Vitorio Imports & Store! Este Memory Card transforma o seu PlayStation 2, permitindo rodar jogos via USB (Pen drive/HD Externo) ou Rede. Siga as instruções específicas para o modelo do seu console.

🚀 Atalho de Inicialização Rápida (OPL Direto): Deixamos o seu Memory Card pré-configurado! Se você ligar o console (seja FAT ou Slim) **segurando o botão ❌ (Xis)** no controle, o sistema tentará dar o boot diretamente para a lista de jogos do **OPL**, sem passar pelos menus.

🟩 Método 1: PS2 FAT (Modelos SCPH-3XXXX / SCPH-5XXXX) – Sistema FMCB

O Free McBoot (FMCB) inicia automaticamente na maioria dos modelos FAT.

  1. Desligue o videogame completamente.
  2. Insira o Memory Card da Bitfunx no Slot 1 do console.
  3. Se for utilizar jogos por USB, conecte seu Pen Drive configurado na porta USB do console.
  4. Ligue o console. O menu modificado do FMCB carregará diretamente na tela.
  5. Selecione OPL (Open PS2 Loader) para visualizar e iniciar a sua lista de jogos.

Nota: Se o console ligar na tela rotineira do PS2, acesse a opção "Rotina de Pesquisa" (Browser), selecione o Memory Card e retorne ao menu inicial.

🟦 Método 2: PS2 SLIM (Modelos SCPH-7XXXX / SCPH-9XXXX) – Sistema Funtuna

Os consoles Slim (especialmente a série 90000) possuem travas de BIOS que exigem a inicialização manual do Funtuna.

💡 Dica de Ouro para PS2 Slim: Além do método manual abaixo, configuramos o seu Memory Card para ativar o Funtuna se você ligar o videogame **segurando o botão R1** no controle. Caso o atalho por comando não funcione no seu aparelho devido ao chip de desbloqueio (Matrix), siga o passo a passo manual a seguir:
  1. Insira o Memory Card no Slot 1 e ligue o videogame sem nenhum CD/DVD dentro.
  2. No menu original do PS2, entre em Rotina de Pesquisa (Browser).
  3. Selecione o ícone do Memory Card.
  4. Você verá alguns arquivos de sistema corrompidos ou transparentes (isso é normal e faz parte do exploit). Aguarde cerca de 5 a 10 segundos até que os ícones carreguem completamente.
  5. Pressione o botão 🔴 (Bolinha) duas vezes seguidas para voltar ao menu principal do PS2.
  6. A tela dará uma piscada rápida e o menu hackeado do Funtuna será carregado. Selecione o OPL para jogar.
⚠️ Importante para PS2 Slim: Esse procedimento manual do passo 1 ao 6 (ou o uso do atalho segurando R1) deve ser repetido toda vez que o videogame for ligado do zero.

🛠️ Solução de Problemas (Troubleshooting)

1. Tela travada com o logo do FMCB ou Funtuna

  • Causa: Conflito de hardware ou mau contato nos conectores do Memory Card ou dos dispositivos USB.
  • Solução: Desligue o console. Retire o Memory Card e o Pen Drive. Limpe os contatos do Memory Card soprando ou usando uma borracha escolar macia (com cuidado). Insira-os firmemente de volta e ligue o aparelho novamente.

2. Tela Preta ao iniciar o console ou ao abrir o OPL

  • Causa: Geralmente ocorre por incompatibilidade de resolução com cabos HDMI (como o PS2 to HDMI) ou Pen Drive corrompido/lento.
  • Solução: Se usa PS2 to HDMI, teste com o cabo AV original para verificar se dá imagem. Você também pode tentar forçar a inicialização ligando o console e segurando o botão ❌ (Xis) para pular direto para o OPL limpo.

3. Os jogos não aparecem na lista do OPL

  • Causa: O Pen Drive ou HD Externo não está formatado corretamente ou os jogos foram transferidos para as pastas erradas.
  • Solução: O dispositivo USB obrigatoriamente deve estar formatado em FAT32. Jogos em formato .ISO devem ficar dentro da pasta chamada DVD (em maiúsculo) na raiz do Pen Drive. Jogos maiores de 4GB precisam ser divididos usando o programa USBUtil.

4. O console liga direto no menu padrão (rotina de pesquisa) e não altera o sistema

  • Causa: A BIOS do seu PS2 Slim (especialmente modelo 90010 com data code recente) bloqueia a inicialização automática, ou o chip Matrix está interferindo nos comandos de atalho.
  • Solução: No caso do Slim, certifique-se de fazer o Método 2 (Funtuna) de forma manual entrando na Rotina de Pesquisa. Se o console tiver chip Matrix clonado, ele pode bloquear os atalhos de botão (R1 ou Xis). Nesse caso, tente desativar o chip temporariamente (ligue o console segurando o botão Start até aparecer "Disabled", depois resete o console e tente os procedimentos).
